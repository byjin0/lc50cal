GraphPad Prism model: log(inhibitor) vs. normalized response
\[ Y = Bottom + \frac{Top-Bottom}{1 + 10^{(LogIC50-X)\times HillSlope}} \]
\[ X = \log_{10}[I] \]
\[ Y = Bottom + \frac{Top-Bottom}{1 + \left(\frac{[I]}{IC_{50}}\right)^{-HillSlope}} \]
For this calculator: Top = 100, Bottom = 0, HillSlope = −1, so
\[ Y = \frac{100}{1 + \frac{[I]}{IC_{50}}} \]
How is this related to the inhibitory Emax model?
The inhibitory Emax model is
\[ E = E_0 - \frac{I_{max}[C]}{IC_{50} + [C]} \]
If the maximum inhibition equals the baseline response, so that \(E_0 = I_{max}\), then
\[ E = E_0 - \frac{E_0[C]}{IC_{50} + [C]} \]
\[ E = \frac{E_0 IC_{50}}{IC_{50} + [C]} \]
\[ E = \frac{E_0}{1 + \frac{[C]}{IC_{50}}} \]
Therefore, when \(E_0 = 100\), the lower asymptote is 0, and \([C] = [I]\), this becomes
\[ E = \frac{100}{1 + \frac{[I]}{IC_{50}}} \]
which is exactly the same form used by this calculator when Top = 100, Bottom = 0, and HillSlope = −1.
